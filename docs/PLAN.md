# Plan — `cash_manager`: marcas `Item:` en vez de marcas `Row:`

## Why

`webtyp.com/model` v0.2.8 reemplaza `model.Row`/`model.RowOf` (un runtime walk que `view` re-ejecutaba O(N²) veces por
lista) con UN tipo, `model.Item{ID, Label, Description, Badge}`, y una marca de campo que nombra su slot
(`Item: model.ItemLabel` / `ItemDescription` / `ItemBadge`). `ormc` v0.1.26 genera un tipado `func (m *X) Item()
model.Item` desde esas marcas, y `webtyp.com/view` v0.6.48 lista solo records que lo tienen (`view.Record`),
computando cada item una vez. `view.Item` se fue: todo habla `model.Item`. Breaking change, sin capa de compatibilidad.

## Tools

```
go install webtyp.com/devflow/cmd/gotest@latest
go install webtyp.com/ormc/cmd/ormc@v0.1.26
go get webtyp.com/model@v0.2.8
go get webtyp.com/view@v0.6.48
```

`ormc@v0.1.26` rechaza un campo todavía escrito `Row: …` («Field.Row fue reemplazado por Field.Item»): ese error significa que
faltó una marca en Stage 1.

## Ecosystem search / Design gate

Reutiliza `model.Item`, `model.ItemLabel/ItemDescription/ItemBadge` (model v0.2.8) y el `Item()` que `ormc`
genera; no hay nombre exportado nuevo aquí. Elimina cada marca `Row:` y cada llamada `model.RowOf` (ver el
`webtyp/model` v0.2.8 README para el gate completo).

## Stage 1 — renombrar las marcas (`model.go`), luego regenerar

En cada `model.Definition`: `Row: model.RowTitle` → `Item: model.ItemLabel`; `Row: model.RowDetail` →
`Item: model.ItemDescription`; `Row: model.RowBadge` → `Item: model.ItemBadge`. Luego `go mod tidy` y `ormc`: cada
modelo listado obtiene un `func (m *X) Item() model.Item` generado en `model_orm.go`.
Check: `grep -rn "Row: model\." --include=*.go .` → empty; `grep -c "Item() model.Item" model_orm.go` ≥ 1.

## Stage 2 — code and tests

- Cada `model.RowOf(&x)` (tests incluidos) → `x.Item()`; `.Title` → `.Label`; `.Detail` → `.Description`.
- Cada `view.Item` → `model.Item`.
- Hand-written test doubles usados como listed records implementan `Item() model.Item` ellos mismos.
Check: `grep -rn "RowOf\|model.Row\b\|view.Item\b" --include=*.go .` → empty.

## Stage 3 — test that the generated item is right

`tests/`: el existente `TestRowsDeclaredOnFields` (o equivalente) es renombrado `TestItemsDeclaredOnFields` y asegura
`rec.Item()` per listed model (`ID`, `Label`, `Description`, `Badge`). A date badge is seconds since 1970.

## Stage 4 — Spanish

Cada comentario o doc de este repositorio que mencione `Row`, `RowOf`, `RowTitle`, `RowDetail` o `RowBadge` es reescrito en español
con los nuevos nombres (`Item: model.ItemLabel`…, «`Item()` lo genera ormc»).
